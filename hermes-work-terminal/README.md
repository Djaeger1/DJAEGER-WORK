# HERMES WORK Terminal v0.1

Native Android terminal client for the HERMES WORK Remote Bootstrap.

Default server:
- http://192.168.42.129:8765

Authentication:
- X-Hermes-Token header
- Token is entered once in Settings and stored on the controller phone.

Supported:
- /health
- /api/exec
- /api/log
- dashboard shortcut

This app is intended for the user's private LAN/OpenWrt network.
